# Superstore Analytics Project

A concise Python data analysis project using **Pandas** and **Matplotlib** to explore Superstore sales performance, customer trends, and profitability.

## Overview
This project analyzes sales and profitability across product categories, regions, and discount levels to identify key business insights and drivers of operating losses.

**Key Steps:**
* **Data Cleaning:** Handling missing values, removing duplicates, fixing data types, and stripping text whitespace.
* **Exploratory Data Analysis (EDA):** Computing key metrics (Sales, Profit, Profit Margin) grouped by category, region, and discount status.
* **Data Visualization:** Creating bar charts, histograms, and trend lines to present key findings.

## Key Insights
* **Top Sales Category:** **Technology** generates the highest overall sales revenue.
* **Most Profitable Region:** The **West** region yields the highest total net profit.
* **Impact of Discounts:** Discounts above **20%** consistently result in negative profit margins.
